Dynamic Feature Visibility Principle

How client isolation and hardware feature gating operate seamlessly in this platform.

1. Dynamic UI Customization

When you select a machine above, the navigation tabs and configuration forms dynamically adjust. If a machine only has QR payments, coin settings are completely hidden.

2. Server-Side Policy Guards

Frontend hiding is not our security perimeter. Every API endpoint enforces require_device_module dependencies, rejecting disabled features with HTTP 403 Forbidden.

3. Zero-Firmware Recompilation

Hardware prices, pulse ratios, and active modules are managed as versioned configuration records. Updating them notifies the device without touching C/C++ firmware.
